# BMI Calculator - A Pythonn learning project

A simple command-line BMI calculator written in Python 3 as a learning project.

## Features

* Supports metric(kg, m) and imperial (lb, ft, in) units.
* Converts imperial measurements to metric.
* Calculates BMI using weight and height.
* Includes basic input validation

## How to run

Requires Python 3.
```bash
python3 main.py
```

Follow the prompt to enter your measurements.
